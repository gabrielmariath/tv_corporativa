# TV Corporativa

Sistema local de TV corporativa para exibição de comunicados internos, banners, avisos e informações institucionais em telas corporativas.

O projeto foi desenvolvido com foco em comunicação interna, permitindo que empresas exibam conteúdos em TVs ou monitores de forma simples, organizada e profissional.

---

## Visão geral

A TV Corporativa é uma solução local para empresas que desejam centralizar comunicados internos em uma tela dedicada.

A aplicação pode ser utilizada em:

- Recepção
- Escritórios
- Refeitórios
- Áreas administrativas
- Ambientes operacionais
- Salas de descanso
- Setores internos

---

## Funcionalidades

- Exibição de comunicados internos
- Painel administrativo local
- Cadastro e atualização de avisos
- Exibição de banners
- Estrutura baseada em JSON
- Execução local com Node.js
- Arquivos `.bat` para facilitar a instalação e inicialização
- Possibilidade de uso em tela cheia

---

## Tecnologias utilizadas

- Node.js
- JavaScript
- JSON
- Batch Script
- HTML
- CSS
